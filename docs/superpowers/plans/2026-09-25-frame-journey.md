# «Путь кадра» — план реализации

> Исполнение: Native (реализую сам в этой сессии; независимые фигуры могут уходить параллельным агентам по контракту из задачи 1), в конце — независимое ревью всей работы. Отступление от шаблона: шаги без полного кода — проект творческий и большой, код пишется сразу в файлы, а проверяемость обеспечивают тесты и скриншоты.

**Goal:** интерактивная страница-онлайн-кинотеатр, которая по-настоящему кодирует, упаковывает и проигрывает фильм в браузере и объясняет путь кадра от мастера до экрана ТВ.

**Architecture:** обычные скрипты в пространстве имён `FJ` (без ES-модулей ради `file://`), движок (film → farm → asset → mp4/net/abr/player, cdn) и главы-фигуры, каждая с `mount/start/stop`, активируемые IntersectionObserver.

**Tech Stack:** vanilla JS, Canvas 2D, WebGL2, WebCodecs, WebCrypto, MediaCapabilities/EME (пробы), node (тесты и сборка), Playwright (проверка).

**Spec:** `docs/superpowers/specs/2026-09-25-frame-journey-design.md`

## Global Constraints

- Работает двойным кликом по `index.html` (`file://`), без сборки и сервера; без `type="module"`, без `fetch` локальных файлов.
- Artifact-сборка — один HTML без `<html>/<head>/<body>`, внешние ресурсы только Google Fonts.
- Шрифты: Sofia Sans Extra Condensed, Golos Text, JetBrains Mono, Handjet (все с кириллицей), у каждого запасной стек.
- Весь текст на русском, «ёлочки», длинное тире с пробелами, неразрывные пробелы после коротких предлогов и между числом и единицей, буква «ё».
- Функциональный текст ≥ 12 px, абзацы ≥ 14 px, контраст ≥ 4,5:1.
- 0 ошибок консоли; `localStorage` только в try/catch; анимации на rAF с паузой при `document.hidden`.
- Сервис вымышленный; реальные компании — только в фактах со ссылками.

## Review Focus

1. Нет WebCodecs (старый Safari, Firefox Android) → модельный режим, страница живая и честно помечена.
2. Слабое устройство не успевает кодировать → верхнее качество отключается, плеер не упирается в ещё не закодированные сегменты.
3. Вкладка скрыта и возвращена → часы плееров и симуляций не прыгают, декодеры не копят кадры.
4. Узкий экран 390 px → нет горизонтальной прокрутки, фигуры читаемы.
5. Быстрое переключение трасс/устройств/алгоритмов во время загрузки сегмента → нет гонок, старые загрузки отменяются.

### Task 1: Каркас и дизайн-система
**Files:** `index.html`, `style.css`, `js/00-util.js`, `js/01-charts.js`
- Токены, шрифты, раскладка глав (текст + фигура), закреплённая линия сигнала, стилизованные контролы (кнопки-сегменты, ползунки, переключатели).
- `FJ.fmt` (числа с неразрывными пробелами, единицы), `FJ.rng`, `FJ.loop` (rAF, пауза при скрытии), `FJ.figure(name, {mount, start, stop})` + автоактивация по видимости.
- Проверка: Playwright — 0 ошибок, скриншоты 1440×900 и 390×844.

### Task 2: Фильм «Восемь планов»
**Files:** `js/10-film.js`
- Таблица планов (секунды, названия, «слабость»), WebGL2-шейдеры планов, 2D-оверлеи (полосы, слейт, отсчёт, титры, прожиг).
- **Produces:** `FJ.film = {W:1280, H:720, FPS:24, FRAMES:1536, shots, shotAt(i), render(i) → canvas}`.
- Проверка: кадры из каждого плана на скриншоте; детерминизм (хэш двух рендеров одного кадра совпадает).

### Task 3: Ферма и хранилище
**Files:** `js/20-farm.js`, `js/21-asset.js`
- Лесенка из 5 качеств, выбор кодека (High → Main → Baseline), ключевые кадры на границах сегментов, сбор кадров, сегменты по 2 с, статистика; модельный режим без WebCodecs; адаптация к скорости.
- **Produces:** `FJ.asset = {rungs, segCount, segDur, frames[r][], segments[r][k] = {bytes, frames:[...], key, peakKbps}, ready(r,k), on(evt)}`.
- Проверка (в браузере): 32 сегмента на качество, каждый начинается с ключевого кадра, средний битрейт в пределах ±60 % от цели.

### Task 4: Сеть, ABR, плеер
**Files:** `js/30-net.js`, `js/31-abr.js`, `js/32-player.js`, `js/33-devices.js`, `tests/abr.test.js`, `tests/net.test.js`
- Трассы, загрузка с RTT по кусочно-постоянной ёмкости; алгоритмы Throughput/EWMA, BBA-0, BOLA (параметры как в dash.js), RobustMPC (горизонт 5, гармоническое среднее, дисконт по ошибке); плеер: планировщик, буфер, остановки, декодирование WebCodecs, вывод кадров по часам, метрики.
- Тесты node: время загрузки на ступенчатой трассе; BBA выбирает минимум в резервуаре и максимум за подушкой; BOLA на пустом буфере выбирает нижнюю ступень, на полном — верхнюю; MPC не выбирает ступень, ведущую к остановке на стабильной трассе.

### Task 5: Герой «Сеанс»
**Files:** `js/50-hero.js`
- Плеер + телеметрия + мультивьюер из пяти мониторов (декодированные качества), прогресс фермы.

### Task 6–15: Главы
- 6 `js/51-master.js` — калькулятор сырого видео, лупа Y/Cb/Cr, waveform и вектороскоп.
- 7 `js/52-shots.js` — детектор склеек, тепловая карта фермы.
- 8 `js/53-codec.js` — сейсмограф кадров, выравнивание GOP, пробы кодеков.
- 9 `js/54-ladder.js` — эксперимент per-shot (GPU PSNR, оболочки, постоянный наклон, экономия).
- 10 `js/22-mp4.js`, `js/23-h264.js`, `js/55-package.js`, `tests/mp4.test.js` — мультиплексор и разбор (круговая проверка), байтовая карта, cbcs, манифесты, лицензия, A/B-водяные знаки.
- 11 `js/40-cdn.js`, `js/56-cdn.js`, `tests/cdn.test.js` — модель CDN (Че против симуляции LRU), карта, события.
- 12 `js/57-player.js` — гонка ABR, мысли алгоритмов, трассы и рисование трассы, устройства, водопад старта.
- 13 `js/58-tv.js` — ТВ-интерфейс с пультом и предзагрузкой, зоопарк платформ, пиксели на градус, ограничения.
- 14 `js/59-live.js` — бюджет задержки, «ГОЛ!».
- 15 `js/60-scale.js` — метрики, рекорды, источники.
Каждая: проверка скриншотом и главным взаимодействием через Playwright, 0 ошибок.
